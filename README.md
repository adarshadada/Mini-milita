# Mini Militia Inspired 2D Shooter

A small original browser game prototype inspired by the general feel of local 2D arena shooters.
It does not use Mini Militia assets, names, characters, maps, or copyrighted code.

## Run
Open `index.html` in a modern browser.

## Controls
- A / D: move
- W: jump
- Mouse: aim
- Left click: shoot
- R: reload
- 1 / 2 / 3: switch weapons
- P: pause

## Included
- Canvas-based physics
- Platforms
- Bots
- Multiple original weapons
- Health and ammo
- Respawn
- Pickups
- Score
- Mobile touch controls
- Simple procedural graphics
